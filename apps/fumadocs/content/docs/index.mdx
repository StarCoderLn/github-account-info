## 文档与事实来源

- 本知识库解释架构、操作顺序、验证方法与踩坑原因。
- `infra/*.yaml` 是 AWS 基础设施的事实来源。
- `packages/db/src/migrations/` 是生产数据库结构的事实来源。
- `specs/4.go-profile-platform/` 保存需求、设计决策和真实验收记录。
- `infra/RUNBOOK.md` 保存线上日常运维与故障处置命令。

当教程与代码出现差异时，先检查代码和 CloudFormation，再更新教程；不要为了匹配旧文档而回退已经验证的安全边界。
